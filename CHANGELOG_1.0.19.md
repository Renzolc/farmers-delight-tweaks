# 1.0.19 (dev)

Containers no longer lose what is inside them when they are decrafted.

- Decrafter block and Decrafter Upgrade: a decrafted container hands back everything it holds first, then its own decraft results. If the contents and the results do not all fit (the 9 output slots, or the backpack), nothing is used up and the container waits. In the Decrafter block, a container whose contents could never fit in 9 empty output slots (a full shulker box) passes through whole instead of blocking the input.
- Before this, the Decrafter block never emptied anything (shulker boxes, backpacks, Sophisticated chests and toolboxes lost their items), and the Decrafter Upgrade only knew Sophisticated storage and a few vanilla containers.
- Read and emptied: shulker boxes, bundles (including the VanillaBackport colours), decorated pots, charged crossbows, pick-block copies of chests/barrels/furnaces/hoppers/cabinets/baskets/shelves/crates, Sophisticated Backpacks and Storage (inventory + upgrades, including Sophisticated Emerald Upgrade chests and barrels, which 1.0.18 missed because they live in another namespace), Sophisticated upgrades with an inventory, Create toolboxes (all colours), Supplementaries safe/sack/presents/jar/urn/quiver/lunch basket (the quiver also covers EasyQuivers, which only adds a recipe), Farmer's Delight and Miner's Delight cooking pots (meal) and skillet, Tide rods (bait, hook, line, bobber) and fish satchel, Construction Wand cores and void sack.
- Create packages (all cardboard and rare packages, including Create: Dragons Plus ones) are unwrapped: the contents come out and the package is used up. An empty package passes through.
- Passed through unchanged, never decrafted, because their contents cannot be returned safely: Create minecart contraptions, Some Assembly Required sandwiches, Sophisticated Storage in Motion carts/boats, anything with a fluid (Sophisticated tank upgrade, Supplementaries jar with liquid), a mob (cage, jar, beehive with bees), a loot table that has not been rolled, block entity data from a pick-block copy, a linked Sophisticated storage endpoint, or any other component or custom data that holds items this mod does not know how to read.
- Farmer's Delight cutting board: cutting a container that still holds items (this mod adds cutting recipes for Sophisticated chests, backpacks, the Create toolbox...) is refused with a message. Take it off the board and empty it first.
- The rules live in `fd_storage_compat/container_rules.json`. Mod components are looked up by id, so Create, Supplementaries, Tide and the rest stay optional.
- Tests: `./gradlew test` (JUnit in a bootstrapped game) and `./gradlew checkContainerCoverage` (checks every container item found in the pack scan is emptied or passes through).
